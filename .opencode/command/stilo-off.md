---
description: Desliga o pipeline do Stilo Code até o próximo /stilo
---

Crie o arquivo-flag vazio `~/.stilo/off` (no Windows, `%USERPROFILE%\.stilo\off`), criando o diretório se preciso, e confirme em uma linha: `Stilo Code desligado — /stilo religa.`. Não apague nem altere nenhum `state.json`: o projeto continua exatamente na fase em que está. Responda no idioma em que o usuário escreveu.
